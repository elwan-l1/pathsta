# Security Policy

## Supported Versions

Only the latest released version of Pathsta receives security fixes.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue.

Report them through [GitHub Security Advisories](https://github.com/elwan-l1/pathsta/security/advisories/new). Include the affected version, reproduction steps, potential impact and any suggested fix.

You can expect a response within a few days.

## Scope

Pathsta is a local macOS menu-bar application. Reports involving unintended filesystem access or modification, unsafe Finder automation, update authenticity, or unintended code execution are in scope.
